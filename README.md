# MyMission App

A clean, minimalistic task management web application designed to help you organize and track your daily missions efficiently.

## Features

- **Add Missions**: Quickly add tasks with the input field and Add button
- **Complete Missions**: Click on any mission to mark it as complete (strikethrough effect)
- **Delete Missions**: Remove unwanted tasks using the × button
- **Persistent Storage**: All missions are saved to localStorage and persist across browser sessions
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Modern UI**: Clean gradient background with smooth interactions

## Tech Stack

- **HTML5**: Structure and markup
- **CSS3**: Styling with gradients, flexbox, and custom checkboxes
- **Vanilla JavaScript**: DOM manipulation and localStorage integration

## Installation & Usage

1. **Clone or download** the project to your local machine
2. **Open** `index.html` in any modern web browser
3. **Start adding** your missions!

No build tools or server required—runs directly in the browser.

## How It Works

1. Type your mission in the input field
2. Click **Add** or press Enter to create the task
3. Click on a mission to toggle completion status
4. Click the **×** icon to delete a mission
5. All changes are automatically saved to browser localStorage

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge
- Any modern browser with localStorage support
